# 🧳 여행 추천 서비스

## 📌 프로젝트 소개

사용자의 여행 계획과 취향을 바탕으로 **여행지 및 관련 정보를 추천하고, 지도 서비스를 통해 이동 정보를 제공하는 여행 추천 서비스입니다.**

사용자와의 자연스러운 대화를 통해 여행 정보를 제공할 수 있도록 **GPT API**를 활용하고, **TMAP API**를 연동하여 여행지의 위치 및 이동과 관련된 정보를 제공하는 것을 목표로 했습니다.

---

## ✨ 주요 기능

### 맞춤형 여행 정보 제공

- 사용자의 여행 계획과 입력 정보를 바탕으로 여행 관련 정보 제공
- **GPT API**를 활용한 자연스러운 여행 정보 및 추천 기능 구현
- 여행 계획 수립에 필요한 정보를 한곳에서 확인할 수 있도록 구성

### 지도 및 위치 정보 연동

- **TMAP API**를 활용한 지도 및 위치 정보 제공
- 여행지의 위치와 이동에 필요한 정보를 확인할 수 있도록 구현
- 추천된 여행 정보를 지도 서비스와 연계하여 사용자 편의성 향상

### 사용자 중심 서비스 구성

- 여행 정보를 직관적으로 확인할 수 있는 화면 구성
- 다양한 여행 정보를 쉽게 탐색할 수 있도록 사용자 경험 개선
- 여행 계획부터 정보 확인까지 편리하게 이용할 수 있는 서비스 구현

---

## 🔗 API 연동

| **API** | **활용 내용** |
|---|---|
| GPT API | 사용자 입력을 기반으로 여행 관련 정보 및 맞춤형 추천 제공 |
| TMAP API | 여행지 위치 및 지도 관련 정보 제공 |

## 💡 프로젝트를 통해 얻은 경험

외부 API를 서비스에 연동하는 과정에서 각 기능의 특성에 맞는 데이터를 활용하고, 여러 서비스를 하나의 사용자 경험으로 연결하는 방법을 경험했습니다.

특히 **여행 정보 추천 기능과 지도 기반 위치 정보를 결합**하여 단순한 정보 제공을 넘어 사용자가 실제 여행 계획을 세우는 데 활용할 수 있는 서비스를 구현하고자 했습니다.
